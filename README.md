# Diwali Delight Showcase

Build a modern, premium, mobile-first seasonal Diwali product catalogue website.



Use the attached website mockup as the visual reference for the overall layout, spacing, typography, navigation, cards, and dark navy + warm gold festive aesthetic.



IMPORTANT:

This is the FRONTEND ONLY for now. Do not create payments, checkout, delivery functionality, or any system for purchasing regulated products.



Create these pages:



1. HOME

- Premium Diwali hero section

- Business logo/name placeholder

- Short tagline

- "Explore Products" CTA

- Product category cards

- Featured products section

- About the business

- Contact/footer



2. PRODUCT CATALOGUE

- Category navigation

- Search bar

- Product cards

- Product image

- Product name

- Price

- Short description

- Availability badge

- View Product button

- Responsive grid



3. PRODUCT DETAILS

- Large product image

- Product name

- Price

- Description

- Category

- Availability

- Back to catalogue button



4. OWNER DASHBOARD MOCKUP

Create a separate /admin page showing:

- Dashboard overview

- Product list

- Add Product button

- Edit product

- Delete product

- Upload product image

- Product name

- Category

- Price

- Availability toggle



For now, use sample product data and placeholder images.



Make the design look like a real professional business website, NOT an AI-generated template.



Prioritize:

- excellent mobile design

- clean typography

- smooth hover/transition effects

- strong visual hierarchy

- fast loading

- accessible buttons and navigation

- consistent spacing

- premium festive aesthetic



Do not add unnecessary features.
